{%- comment -%} Get the post's description or AI summary, falling back to body content. Arguments: full_text: If true, return the full content. Default is false. max_length: The maximum length of the returned content. Default is 200. Override of the theme include: when an AI summary exists for the post (site.data.summaries, generated in CI), it is shown instead of the raw description/content. full_text=true (search index) keeps the full content. {%- endcomment -%} {%- assign ai_summary = site.data.summaries[post.name] -%} {%- if ai_summary and ai_summary.text and include.full_text != true -%} {{- ai_summary.text -}} {%- else -%} {%- if post.description and include.full_text != true -%} {{- post.description -}} {%- else -%} {%- comment -%} Remove the line numbers from the code snippet. {%- endcomment -%} {%- assign content = post.content -%} {%- if content contains '
' -%}
      {%- assign content = content
        | replace: '
',
          '' -%}
    {%- endif -%}

    {%- assign content = content
      | markdownify
      | strip_html
      | newline_to_br
      | replace: '
', ' '
      | strip_newlines
      | strip
    -%}

    {%- unless include.full_text -%}
      {%- assign max_length = include.max_length | default: 200 -%}
      {%- assign content = content | truncate: max_length -%}
    {%- endunless -%}

    {{- content -}}
  {%- endif -%}
{%- endif -%}
